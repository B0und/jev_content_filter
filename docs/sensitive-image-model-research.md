# Sensitive illustration model candidates

Research date: 2026-10-02. This note identifies models worth measuring on the supplied X image and a small set of safe controls. Model cards do not establish that a model will catch that image. Published accuracy numbers below come from different datasets and must not be compared as a shared benchmark.

The requested boundary includes sexualized illustrations without explicit sexual acts. A binary explicit-content detector or a classifier that treats all non-hentai drawings as safe can miss that boundary. A four-level anime rating model provides a `sensitive` class separately from `questionable` and `explicit`.

## Executable inference approaches

**DeepGHS ONNX:** download `<variant>/model.onnx` and `<variant>/meta.json` at the pinned revision. The [first-party classifier](https://github.com/deepghs/imgutils/blob/main/imgutils/generic/classify.py) composites transparency on white, converts to RGB, bilinearly resizes directly to model input height/width, encodes NCHW float32, and normalizes each channel with `(pixel / 255 - 0.5) / 0.5`. It feeds `input` and reads `output`, which contains probabilities already; do not softmax them again. Inspect ONNX metadata for the exact input dimensions. The small MobileNet model can use ONNX Runtime Web directly without a Transformers conversion. `sensitive + questionable + explicit` is a possible broad filter score, but validate safe-control behavior before adopting a threshold.

**WD ONNX:** use the author's [reference inference code](https://huggingface.co/spaces/SmilingWolf/wd-tagger/blob/main/app.py). Composite on white, pad to a square on white, bicubic resize to 448px, RGB→BGR, NHWC float32 **0–255**. This preprocessing differs from DeepGHS. Outputs already contain tag/rating scores; CSV category `9` marks rating labels, `0` general tags, `4` characters. Do not apply a global softmax across thousands of tags or assume a tag's presence proves sexual content.

**Marqo:** `timm.create_model("hf_hub:Marqo/nsfw-image-detection-384", pretrained=True)`, `.eval()`, and `timm.data.create_transform(**timm.data.resolve_model_data_config(model), is_training=False)` are the [author's reference path](https://huggingface.co/Marqo/nsfw-image-detection-384/blob/0c26ec22111b83f106d72a55f611ec35962bcb65/README.md). Its config uses bicubic 384px preprocessing, mean/std 0.5, and labels in the order NSFW then SFW. Apply softmax to logits. After measuring PyTorch, export with `torch.onnx.export` using `[1,3,384,384]`, compare ONNX probabilities to PyTorch, and test the actual extension's WASM execution provider before selecting it.

**SigLIP variants:** use `AutoImageProcessor.from_pretrained(repo, revision=pin)` and `SiglipForImageClassification.from_pretrained(repo, revision=pin)`, then softmax `model(**processor(images=image, return_tensors="pt")).logits`. Both processors inspected use bilinear direct resize and channel mean/std 0.5. Use their actual config label maps, which differ between variants. Export ONNX and measure quantized accuracy if browser adoption is justified; no ready upstream ONNX artifact was found.

## Baseline and selection

[Falconsai/nsfw_image_detection](https://huggingface.co/Falconsai/nsfw_image_detection) is a binary `normal`/`nsfw` ViT trained on a proprietary ~80k-image dataset. It has no separate sensitive-anime label. The [onnx-community conversion](https://huggingface.co/onnx-community/nsfw_image_detection-ONNX/tree/1ceb3c7fe1e9f3f2507e6df577437f23a9149fd5) provides a 343,401,688-byte full model, 87,333,629-byte int8 model, and 49,718,585-byte q4f16 model. Keep it as a measured baseline rather than interpreting its published accuracy as evidence about the supplied post.

Start with DeepGHS MobileNet and Marqo; measure DeepGHS CaFormer and WD as stronger/larger comparators. Measure SigLIP variants if those do not separate the example from safe controls. Record the exact image hash, preprocessing, revision, raw output probabilities, load/inference times, and control-set false positives. Choosing a model only because it gives one desired answer is insufficient.
